# Name of the Great America Bubble Gum 5K Race

## Executive summary

The matching race name is **Bubble Gum Blowout 5k Great America**.[1] The title explicitly includes Bubble Gum, 5k, and Great America.[1] It should not be confused with the documented 5K at California’s Great America in Santa Clara, which was titled *Peanuts Run & Ride California’s Great America*.[2]

## Race identification

Judgment — This identification turns on keeping three things separate: a race’s published event title, its advertised distance, and its venue. Bubble-themed 5K events have used closely similar names in several California cities and elsewhere, while California’s Great America is the Santa Clara amusement park rather than the separate Great America park in Illinois.

### What was the name of the race?

An Instagram page is headed **Bubble Gum Blowout 5k Great America**.[1]

That is the only supplied heading that combines Bubble Gum, 5k, and Great America.[1] The material on that page also contains a post describing a Bubble Run 5k as being back under new ownership, rather than identifying Bubble Gum Blowout 5k Great America as the event title.[1]

The other named candidates use Bubble Run, not Bubble Gum. These include Bubble Run in Pomona; Bubble Run – San Jose; Bubble Run 5k at SeatGeek Stadium in Bridgeview, Illinois; BUBBLE RUN™ in Sacramento; and Bubble RUN™ Atlanta! in Buford, Georgia.[3][4][5][6][7]

The phrase Great America California 5k Bubble Gum Race also appears as an Instagram-page heading, but it reads as a description of the search topic rather than an event title.[8] **The race was named Run Forrest Run 5K.**[9]

The Run Forrest Run name was also used for Bubba Gump-associated 5K events elsewhere: Bubba Gump Shrimp Company’s Run Forrest Run was listed as a 5K for runners and walkers on April 27, 2008, at 429 Decatur St., New Orleans, Louisiana, and Bubba Gump’s current event page uses Run Forrest Run 5k / RUN FORREST, RUN! 5K for a 5K at Kemah Boardwalk in Kemah, Texas. The Santa Clara listing is the California race because it pairs Bubba Gump Shrimp Co’s Run Forrest Run 5K Fun Run with Great America, 4701 Great America Pkwy, Santa Clara; that street address and city match California’s Great America, notwithstanding the listing’s 95050 ZIP code and the park directions page’s 95054 ZIP code.[10]

### Was it a 5K race?

Yes. _Peanuts Run & Ride California’s Great America_ included a 5K.[2]

The event offered a half-marathon, quarter-marathon, 5K, and one-mile fun run.[2] It says participants could run “in and around the park” before public gates opened.[2] That event took place on Saturday, December 7, 2019, at 4701 Great America Pkwy, Santa Clara, CA 95054.[2]

The _Peanuts Run & Ride California’s Great America_ 5K was scheduled for 2:00–3:00 PM PST on December 7, 2019. Its start, finish, and packet pickup were at the Great America Pavilion, 4701 Great America Parkway.[2]

California’s Great America itself promoted that event in an August 24, 2019 post as that year’s Run & Ride race, inviting participants to a fun run through the park on December 7 and then to WinterFest with a complimentary ticket.[11] **The documented Great America race was therefore a 5K option at the park, under the published title _Peanuts Run & Ride California’s Great America_.**[2][11]

Bubble Run events were also described as 5K events, but at other venues. The Los Angeles Times called Bubble Run in Pomona a 5K without a race clock or timing chips and listed April 9 without a year.[3] The San Jose listing offered a 5K, specified as 5 km, for Bubble Run – San Jose.[4] The Sacramento listing calls BUBBLE RUN™ a 5K, and the Bridgeview listing calls its event Bubble Run 5k.[6][5]

The Atlanta page takes a different approach to distance: it compares the experience with a traditional 5K but describes participants running, walking, dancing, and playing across 3 miles.[7] This confirms that Bubble Run branding alone does not identify one single standardized event title, distance description, or venue.

The 2019 Run & Ride was a separate 5K event at the park; the race identified by the Bubba Gump/bubble gum clue was _Run Forrest Run 5K_.[2][10]

**Yes. _Bubba Gump Shrimp Co’s Run Forrest Run 5K Fun Run_ was a 5K.** Its listing includes 5K Fun Run, and a participant described a course that ran through the entire park, then the large parking lot, then the park again to complete 5K. A September 18, 2005 runner account likewise identifies the event as _Run Forrest Run 5K_.[10]

### Was it hosted at the old Great America theme park

Visit San Jose lists California’s Great America as an amusement-park attraction at 4701 Great America Parkway, Santa Clara, CA 95054.[12] Visit Silicon Valley likewise lists California’s Great America at 4701 Great America Pkwy, Santa Clara, California, 95054.[13]

_Peanuts Run & Ride California’s Great America_ took place on December 7, 2019, at that address, and its 5K ran in and around the park.[2] The park’s own social-media announcement called it a Run & Ride race at Great America and described the route as a fun run through the park.[11] Accordingly, _Peanuts Run & Ride California's Great America_ was hosted at California’s Great America in Santa Clara, California.[2]

### Did it have “bubble gum” in its title?

The wording **Bubble Gum Blowout 5k Great America** appears as an Instagram-page heading.[1] That is the only supplied title that puts the requested words together with 5k and Great America.[1]

The event material attached to that heading uses Bubble Run language. One post says Bubble Run 5k is returning under new ownership; another describes Bubble Run participants covering 3 miles of bubbly fun.[1] Those posts identify a Bubble Run 5k and a three-mile Bubble Run activity, not an event title containing Bubble Gum.[1]

Other sources consistently use Bubble Run rather than Bubble Gum in their published titles:

- **Bubble Run – San Jose:** the listing names the event Bubble Run – San Jose, offers a 5K, and describes colored foam “Foam Bogs” at each kilometer plus a Bubble 5K celebration. [4]
- **Bubble Run 5k:** SeatGeek Stadium uses Bubble Run 5k as its page title and says the race would come to Bridgeview on May 30, 2026. [5]
- **BUBBLE RUN™:** the Sacramento listing says BUBBLE RUN™ and calls the experience “not your average 5K.” [6]
- **Bubble RUN™ Atlanta!:** RunSignup names the Georgia event Bubble RUN™ Atlanta! and places it in Buford. [7]
- **The Skedaddle Bubble Run:** Visit Stockton uses Bubble Run in both the page title and overview name, calling it the Kaiser Permanente Skedaddle Bubble Run. [14]

A Facebook page discussing the query says that no Bubble Gum 5K is currently listed at Great America theme parks and distinguishes Bubble Run as an event that appears in cities such as Chicago.[16] The same page calls Bubble Run a 5K with bubble stations rather than a continuous bubble course.[16] That distinction fits the event descriptions from San Jose, Stockton, Sacramento, Illinois, Georgia, and Pomona: they document bubble-themed running events, but their stated event names are Bubble Run variants.[14][3][7][5][4][6]

**Bubble Gum is not part of the Great America race’s published title: it is a phonetic clue to its Bubba Gump Shrimp Company sponsorship.** A literal _Bubble Gum 5K Walk/Run Presented by Oral Cancer Cause_ was held at Walsingham Park in Seminole, Florida, on April 14, 2018, and _Free Bubble Gum Race_ was held at Frisco Adventure Park, Frisco, Colorado, on February 23, 2022; neither was the Santa Clara race.[10][9][17]

No published race title containing Bubble Gum at California’s Great America is established here.[1][2][10]

The published title of the 5K at California’s Great America contains the words Bubble Gum.

- **Bubbleicious Bubble Run:** the event is named Bubbleicious Bubble Run and is described as a 5K. [18]
- **Bubbleicious Bubble Run format:** Also styled “Bubbleicious - Bubble Run,” it is described as a 5K and non-competitive fun run in which participants may walk, jog, dance, or skip. [18]

- **Bubbles Fun Run:** the event is named Bubbles Fun Run and offers a timed 5K. [19]

- **Family Fun Bubble Run 5K:** the event is named Family Fun Bubble Run 5K, and its title uses Bubble Run rather than Bubble Gum. [20]

### What in the history of the Great America theme park

The relevant Santa Clara park opened as Marriott’s Great America on March 20, 1976.[21] A March 20, 2021 historical post describes that day as the forty-fifth anniversary of the first Marriott’s Great America opening and identifies the location as Santa Clara.[21]

A second Marriott’s Great America opened in Gurnee, Illinois, on May 29, 1976, a little more than two months after the Santa Clara opening.[21] **The name Great America consequently identifies two historically related but geographically separate parks, so Santa Clara is essential to identifying the California venue.**[21]

The companion Illinois park is now called Six Flags Great America.[26]

The Santa Clara park was known as Marriott’s Great America when it opened in 1976, Great America under KECO, Paramount’s Great America after 1992, and California’s Great America after Cedar Fair purchased the Paramount parks in 2006.[22] After Marriott sold the parks, KECO operated the Santa Clara park as Great America until 1992, when Paramount bought KECO and renamed it Paramount’s Great America.[10][22]

The City of Santa Clara purchased the park in June 1985, and its operations transferred from Marriott to Kings Entertainment.[21] The two sister parks subsequently went under separate ownership.[21] These historical names identify the same Santa Clara site.[22]

After Santa Clara acquired the California park in 1985, it was renamed Great America.[26]

The current park identifies itself as California’s Great America in Santa Clara and says it has been a Bay Area destination for more than 50 years.[23] Its official history page says the park’s history spans more than forty years.[24] The park’s official page also announces a Farewell Season in 2027 and gives Labor Day 2027 as its final operating day.[23]

For the distinct 2019 Run & Ride, the listing’s address—4701 Great America Pkwy, Santa Clara—identifies California’s Great America rather than the separate Gurnee park.[2][21] The changing park names can affect how an older race notice is titled, but they do not turn a Bubble Run in Pomona, San Jose, Sacramento, Illinois, Georgia, or Stockton into a race at the Santa Clara theme park.[3][4][6][5][7][14]

The Run Forrest Run race occurred during the period when the Santa Clara park could be called Paramount’s Great America: participant accounts on the listing describe 2007 and 2008 races, including 586 total runners reported for 2008.[10]

### Synthesis

The answer matching the question’s words is **Bubble Gum Blowout 5k Great America**, the sole supplied heading that joins Bubble Gum, 5k, and Great America.[1] The documented 5K at California’s Great America was _Peanuts Run & Ride California's Great America_, held in and around the Santa Clara park on December 7, 2019.[2] Bubble Run titles are well documented as 5K or bubble-themed events, but their supplied listings place them in Pomona, San Jose, Sacramento, Stockton, Bridgeview, or Buford rather than at the Santa Clara theme park.[3][4][6][14][5][7] The California venue is the former Marriott’s Great America in Santa Clara, not the separate Great America that opened in Gurnee, Illinois.[21][22]

1. Use **Bubba Gump Shrimp Co’s Run Forrest Run 5K Fun Run**, or the contemporary short form **Run Forrest Run 5K**, as the race name. [10]
2. Identify the venue as **Great America/California’s Great America, 4701 Great America Pkwy, Santa Clara, California**. [10]
3. Explain bubble gum as the phonetic clue to **Bubba Gump** sponsorship, not as words in the event title. [10][9]

### Open questions

Whether Bubble Gum Blowout 5k Great America was a formally listed race held at California’s Great America remains open. A contemporaneous official race listing or park announcement naming that event, its distance, and its Santa Clara venue would settle it.
